# 👨‍💻 About Me

Hi, I'm Saeid. I'm an ICT master's student at the **University of Padova**, with a strong interest in **Computer Vision, 3D Vision, Machine Learning, and Computer Graphics**.

I enjoy working on problems where research and engineering come together, especially around how machines can understand images, video, geometry, and the 3D world.

My work so far has included **real time computer vision, point cloud learning, 3D feature matching, machine learning, graph analysis, NLP, and C++ systems programming**.

Right now, I'm particularly interested in **3D reconstruction, neural rendering, NeRF, Gaussian Splatting, and modern 3D vision methods**.
